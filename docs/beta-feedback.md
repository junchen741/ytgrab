# 先行測試回饋表

請試用一到兩週，有空時回答下面的問題（用 LINE 回覆就可以）：

## 安裝
- [ ] 安裝過程有沒有卡住？卡在哪一步？
- [ ] 防毒軟體有沒有跳出警告、或把檔案刪掉？（請截圖）

## 使用
- [ ] 從貼上網址到存好 MP3，大概花多久？
- [ ] 有沒有哪一步看不懂、不知道下一步要按什麼？
- [ ] 拖拉頭尾的拉桿、紅色區段順不順？有沒有拖不動的時候？
- [ ] 自動標好的範圍（SponsorBlock）準不準？
- [ ] 存到手機後，歌名、演出者、封面有沒有正確顯示？

## 速度
- [ ] 程式開起來、下載、分析波形時，電腦會不會變得很卡？
- [ ] 有沒有遇過程式沒反應、需要強制關閉？

## 其他
- [ ] 有沒有遇到錯誤畫面？（如果有，請把「錯誤報告」傳過來）
- [ ] 最希望增加或修改什麼？
