# YTGrab 音樂抓抓：安裝與使用說明

## 安裝（只要做一次）

1. **用電腦**打開下載連結（在電腦版 LINE 直接點，或複製到瀏覽器的網址列）。點下去就會開始下載 `YTGrab-Setup.exe`。用手機點沒有用，手機不能安裝。

   下載連結：https://github.com/junchen741/ytgrab/releases/latest/download/YTGrab-Setup.exe

2. 瀏覽器可能會說這個檔案「不常下載」或「可能有害」，請選擇保留：
   - Edge：在下載清單按檔案旁邊的 **「⋯」** → **「保留」** → **「顯示更多」** → **「仍要保留」**
   - Chrome：按 **「保留」**
3. 打開下載好的檔案。如果跳出藍色視窗「Windows 已保護您的電腦」：
   - 點左邊的 **「其他資訊」**
   - 再點右下角出現的 **「仍要執行」**

   會出現這些警告，是因為這個軟體沒有花錢向微軟申請簽章，不是病毒。
4. 安裝完成後，桌面和開始功能表會出現「YTGrab 音樂抓抓」。

（如果電腦缺少必要的元件「WebView2」，安裝程式會自動下載，請保持網路連線。）

## 使用方式

1. 在 YouTube 找到歌，複製網址：
   - 電腦瀏覽器：複製上方網址列
   - 手機 App：按「分享」→「複製連結」，再用 LINE 傳給自己，在電腦上複製
2. 打開 YTGrab，把網址貼上，按 **「開始」**。
3. 下載完會看到聲音的波形圖：
   - **暗掉的**是頭尾不要的部分，拖拉兩邊的拉桿可以調整。
   - 想剪掉中間某一段：在波形上**按住滑鼠拖拉**，會出現紅色區段。
   - 按 **「試聽成品」** 聽聽看剪完的樣子。
4. 確認下面的「歌名」和「演出者」沒問題，按 **「存成 MP3」**。
5. 按 **「開啟資料夾」**，用 USB 線接上手機，把 MP3 複製到手機的 **「Music」** 資料夾。

## 更新

有新版時，程式最上方會出現黃色橫幅，按 **「立即更新」** 就好，程式會自己重新開啟。

## 出問題時

照畫面上的說明做。如果畫面寫「請把錯誤報告傳給開發人員」：

1. 按 **「複製錯誤報告」**
2. 打開 LINE，在和開發人員的聊天室裡按「貼上」送出
