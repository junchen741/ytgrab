# YTGrab 音樂抓抓

個人使用的 Windows 小工具：貼上影片網址，把音訊剪輯成 MP3（去頭去尾、刪掉中間段落、加上歌名與封面）。

## 下載

[下載最新版安裝檔](https://github.com/junchen741/ytgrab/releases/latest/download/YTGrab-Setup.exe)

安裝與使用方式見 [docs/install-guide.md](docs/install-guide.md)。
